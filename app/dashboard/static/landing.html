One query. Seven SIEM schemas.

The same event has seven spellings across the industry's schemas. Sherlock normalises them onto one canonical field set first, so a detection — or a hunt query — is portable across all of them.

Write it once, fire it everywhere

A query on the normalised fields runs identically no matter which SIEM exported the event. No rule rewritten per platform.
